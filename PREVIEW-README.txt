VELLORA — Standalone Preview

Cara menjalankan di HP/Code Editor:
1. Buka file VELLORA-preview.html.
2. Gunakan Preview / Open in Browser.
3. Koneksi internet diperlukan karena versi standalone mengambil React, Recharts, SheetJS, html2canvas, dan Babel dari CDN.
4. Versi ini dibuat khusus untuk preview cepat di editor; versi utama React/Vite tetap berada di project root untuk hosting/deployment.

Untuk hosting:
npm install
npm run build
